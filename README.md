# End-to-End Sales Analytics Dashboard

##  Overview
This project is an end-to-end Business Intelligence solution designed to transform raw sales data into actionable business insights. The dashboard tracks key performance indicators (KPIs) such as total revenue, order quantities, and average order values across different regions and time periods.

##  Tech Stack & Tools
* **Data Transformation & Modeling:** Power Query, Star Schema
* **Calculations & Metrics:** Data Analysis Expressions (DAX)
* **Visualization:** Power BI

##  Data Modeling & Architecture
* Built a clean **Star Schema** architecture featuring a central Fact table (Sales transactions) connected to surrounding Dimension tables (Products, Customers, Dates, and Geography) to optimize query performance and reporting accuracy.
* Developed custom **DAX measures** for dynamic aggregations, year-over-year growth, and advanced filtering.
